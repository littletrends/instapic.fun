# Spend UX notes for Instapic side hustle (design only)
When real payments land later — shape like arcade, not casino.

## What to sell
1. **Continues** — “Insert coin” after death; keep depth stigma (depth marked continued)
2. **Coin top-ups** — demo→paid night wallet
3. **Night Pass** — Aura drip cosmetics, ticket frames, foyer lights (no gameplay power)
4. **Curio album slots** — complete sets (Monopoly sticker feeling, soft)
5. **Event entry** — Closing Time / Kill Screen weekend / dunk night
6. **Party pack** — unlock 2P lane night for a booking code (ties to Instapic sessions)

## What NOT to sell
- Pay to skip skill / buy Inferno rank
- Loot boxes with real-money rarity pressure for kids
- Raid anxiety that demands spend to protect

## Session-code bridge (Instapic already has codes)
- Booth session code unlocks web Night Pass trial or bonus curios
- Web spend can unlock Bonus-pack flavour on next real booth visit (side hustle ↔ real cabinets)

## Metrics that mean “people want this”
- D1/D7 return to alley
- Continues per death
- Challenge link opens
- Pass attach rate
- Not: vanity downloads with $0

## Ethical spend checklist (2026 best practice)
- Cosmetics / Night Pass / ticket frames = OK
- Continues = OK (arcade credit; label clearly)
- Convenience (extra demo coins) = OK if core play works free
- Battle/Night Pass: finishable without cruelty; free track has real crumbs
- Never: buy Heat Stage / Inferno, fake odds, raid-anxiety spends for kids
- Show real $ price; soft pack = stricter
