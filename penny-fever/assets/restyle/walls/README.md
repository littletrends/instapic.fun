# Matching paper alley walls

Separate scenery assets — not replacements for the block stalls, rides or papercut hosts.

- `sheets/`: original generated PNG concept turnarounds. Never overwrite the source concepts.
- `runtime/`: WebP encodings of the same complete sheets, with no art changes.
- `prompts.json`: exact generation brief and individual themes for all 37 sets.
- `../../../wall-art-review.html`: contact-sheet review, front/back/left/right.
- `../../../wall-studio.html`: rotatable thin paper-wall preview.

Each sheet: top-left front, top-right finished back, bottom-left left three-quarter,
bottom-right right three-quarter. Side views are design references, **not** four
textures pretending to be a solid building. The viewer builds a thin paper profile
with front and back artwork and real edge thickness.

The locked doors, tunnel hatches and hideaways are decorative concepts. No room,
unlock, collision opening, coin cost or game reward is activated by this work.
Future entrance anchors in the wall catalogue are planning locations, not surveyed
pixel-perfect positions of the generated artwork. Review those before implementing doors.

Made with built-in image_gen, using the supplied parlour/amusement concept sheets
and the first Mystic wall for style consistency. Original generated files also remain
in Codex's generated-images folder. Use the project copies for syncing/backups.
