# Penny Fever — transparent scene turnarounds

76 sets: vendors, stalls, amusement attendants, amusements, Aura and the ticket booth. Each set has front, left, back and right illustrated views plus a preview and a 2×2 atlas. Surroundings are real RGBA transparency.

Open `index.html` directly in a browser. No server is required. Search, collection filter, four view buttons, and inspection backgrounds are in the gallery.

These are illustrated turnarounds, not 3D models. This pack does not change game code.
