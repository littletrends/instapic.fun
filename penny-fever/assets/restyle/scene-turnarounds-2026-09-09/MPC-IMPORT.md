# Mother PC import

Transfer this folder as an asset pack, preserving its internal paths. The Mother PC has newer game code; do not replace Mother's game with the Acer build just to install these assets.

Use each set's `front.png`, `left.png`, `back.png`, `right.png` or `turnaround.png`. Do not use `preview.png` as full-resolution game art. These images already contain alpha: do not colour-key cyan/white again.

The standalone gallery is a four-view art review, not a game integration test.
