Instapic Terms

Simple terms for purchasing and using an Instapic booth code.

Your booth code

After a successful online payment, Instapic issues a unique 6-digit code for the package selected. An unused paid booth code has no expiry date and can be entered at a participating Instapic photo booth or magic mirror operated by Little Trends.

Keep your code safe. Anyone with the code may be able to use the session or view its associated content. Save, screenshot or download it after purchase.

Sessions and digital content

Each code provides the prints and digital features shown for the selected package. Once a code has been used to begin a booth session, it cannot be used to start another paid session unless Little Trends agrees otherwise.

After completing a session, use the same code to retrieve available photos and bonus content. Guests should download and save their content within the retrieval period shown on the website. Instapic is not intended to be permanent cloud storage.

Problems and refunds

If payment succeeds but no code is issued, a valid code is not accepted, or the purchased service cannot be supplied, contact Little Trends through the booth operator or the contact channel used for your booking. We will check the transaction and provide an appropriate solution.

Change-of-mind refunds are not normally offered after a valid code has been issued. Nothing in these terms excludes or limits rights and remedies available under the Australian Consumer Law.

Fair use

Do not attempt to guess, copy, sell, interfere with or misuse another guest’s code, session or private-event content. Access may be restricted where necessary to protect guests or the service.
